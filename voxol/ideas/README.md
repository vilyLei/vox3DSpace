#
一个完整的文件称作一个Space简称为空间。Space可以嵌套组合。
一个Space里面可以放置多个Scope(doc)简称为界, Scope可嵌套。
一个Scope里面可以包含多个Process(Page)简称为过程, Process可嵌套。
上面三者可以自定义封面，封面可以是动图或video。

Process内部直接包含用于构成表达/设计过程的图层(图元): Content Unit.

Scope, Process, Content Unit 这三者可以共同组织为一个表达, 这种表达可以对应到一个实时的拓扑关系表中。

例如在： Space, Scope, Process, Content Unit上点击右键，就可以看到简化版的这种拓扑关系。具体进入到其中，就可以看到全量的拓扑关系了。

#
Space, Scope, Process, Content Unit都可以称之为内容，内容本身可以被复用， 复用过程，只有Content Unit内容会被及时更新。

# 实际用例1
推导一个波动方程，表达思路，公式展示，交互式可视化演示模拟等等。里面可以包含对应的音频视频的修正信息或者讲解信息。
