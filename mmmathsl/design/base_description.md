## 基本信息综述
- 用c++20标准实现相关代码。
- 这里的c++ 20代码实现了一个能解释运行glsl语法风格的mini glsl math runtime的脚本系统。
- 这个脚本系统主要用于执行矢量、矩阵相关的数学运算，以及基于if的逻辑运算。
- 目前的脚步只能支持一个函数，不支持函数嵌套。
- 以PIMP实现头文件及源文件管理机制，保障对源码的封装.以便以一个头文件+一个lib静态库的形式被其他c++系统使用。
- 已经基于glsl的语法风格实现了一个mini glsl math runtime的字节码解析器，包含 Lexer → Parser → Compiler → VM四级流水线。
- 已经实现了七层DoS保护机制。
- simple/src/目录里面的代码实现的是直接解释AST树来执行的脚本代码执行机制。
- simple/tests/目录里面实现的是基于AST边解释边执行的测试代码。
- high_perf目录里面是字节码虚拟机的实现形式，性能更好。
- high_perf/tests/目录里面是全面的字节码解释器系统的总体测试，包括压力测试和glslf风格内嵌函数测试。
- high_perf/tests/里面的测试还包括了内存监测。
